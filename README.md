# RSS 订阅

Coopanion 的 RSS / Atom 订阅扩展。把喜欢的博客、新闻和播客更新交给 Coo：新内容会精简成一条消息告诉你，也可以随时问它“最近有什么新文章”。

- 订阅源管理：RSS / Atom / JSON Feed 地址或站点首页自动发现，添加前可测试解析
- 新内容播报：短窗口内合并多条更新，避免刷屏；每源可设为实时或静默
- 每日晨报：固定时间汇总过去 24 小时的更新与未读
- 启动播报：打开 Coopanion 后立即拉取全部源，并播报本次的新内容
- 收件箱：未读 / 全部 / 星标、标题摘要搜索、批量已读、按源筛选、自动清理
- 全文阅读：按需抓取文章正文交给 Coo，并缓存已抓正文减少重复请求
- 播报预览：面板显示最终文本，并尝试让 Coo 在桌宠气泡里模拟真实播报（依赖 Coo 模型，可能只显示文本；不消费待播报内容）
- OPML 导入导出，方便从其他阅读器迁移
- 无密钥、无遥测；内网与本机 RSS 地址也可以订阅

## 安装

### 从扩展市场

1. 打开 Coopanion →「World 扩展」→「扩展市场」。
2. 搜索 `cortico-world-rss` 或「RSS 订阅」，点安装。
3. 到「World 总览」启用「RSS 订阅」。
4. 打开「RSS 订阅」页面，添加第一个源。

### 从本机目录（开发或试用）

1. Coopanion →「World 扩展」→「手动安装」→ 选择本包根目录。
2. 重启 Coopanion 进程。
3. 到「World 总览」启用，再打开「RSS 订阅」添加源。

## 快速上手

1. **添加订阅**：在「订阅源」页点「添加订阅」，粘贴 RSS 地址或站点首页即可；名称留空会自动识别。检查间隔留空表示使用全局默认值。
2. **选择通知方式**：每个源可以设「实时」或「静默」。静默源只进收件箱，不参与实时、晨报重点和启动播报。
3. **调整通知**：在「通知」页打开每日晨报、设置晨报时刻，或开关「启动时播报最新消息」。
4. **和 Coo 说话**：
   - “订阅 https://example.com/feed”
   - “最近 RSS 有什么新内容？”
   - “把 RSS 里未读的文章读一下，挑重点告诉我”

## 通知是怎么工作的

- **实时**：新条目先进入一个合并窗口（默认 20 秒），窗口结束或攒够条目后合成一条播报。
- **静默**：条目不播报，只出现在收件箱。
- **每日晨报**：每天固定时刻汇总过去 24 小时的收件数与未读数；未读重点最多列 3 条，且只列非静默源。全是静默源的更新时，晨报仍会报统计，但不会展开条目。
- **启动播报**：应用启动后立即拉取全部源，把本次新内容马上播报一次；静默源不参与。
- **上限**：单次播报最多展开 8 条、正文约 1200 字。超过上限的条目不会丢，留到下一波继续播报。

## 配置

大部分配置在面板里改，改完即时生效。

| 设置 | 默认值 | 说明 |
|---|---|---|
| 轮询间隔 | 30 分钟 | 全局默认；单个源可以在订阅详情里覆盖，最低 1 分钟 |
| 播报合并窗口 | 20 秒 | 窗口内的新内容合并成一条播报 |
| 每次播报条目上限 | 8 条 | 一次最多展开几条；超出的顺延到下一波 |
| 单条通知字符上限 | 1200 字 | 一条播报正文的长度预算 |
| 每日晨报 | 关闭 | 打开后可设置晨报时刻，例如 09:00 |
| 启动时播报最新消息 | 开启 | 启动后立即拉取并播报本次新内容 |
| 数据保留 | 30 天 | 全库最多 2000 条、每源最多 200 条；星标条目不会被自动清理 |

更细的选项（并发、超时、字符预算、清理上限等）在「高级」标签里。

## 数据与隐私

- Coo 只访问你添加的源地址，以及你按需抓取全文时的文章页；内网和本机地址也可以。
- 订阅列表和条目保存在本机 Coopanion 的数据目录，不上传，也没有遥测。
- 标题、摘要和正文会随工具调用或播报进入模型上下文（发往你自己配置的模型提供商），这是功能工作的前提。
- 按需抓取的全文会缓存在本机条目库里（受清理规则约束），不会上传。
- 源内容是外部数据，Coo 被要求不把文章内容当成指令执行。

## 常见问题

**Coo 没有播报新内容？**

先确认该源不是「静默」，再检查「通知」页的合并窗口、条目上限、晨报与启动播报开关。也可以看「订阅源」页的状态和最近错误。

**收件箱里有内容，但没有播报？**

静默源只进收件箱；另外，超过单次播报上限的条目会顺延到下一波，而不是立刻出现。

**怎么只看自己关心的内容？**

目前不做关键词过滤。可以在对话里描述主题，让 Coo 先读取未读内容再按主题筛选。

**支持播客或视频吗？**

支持带 RSS / Atom 的播客更新（标题与摘要）；不会下载音视频文件。

**数据存在哪里？怎么清理？**

在 Coopanion 的数据目录。面板「高级」里可以设置保留天数和条目上限；星标条目不会被自动清理。
